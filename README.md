# 🎭 SONSUZ FELSEFE DÖNGÜSÜ

> *"Eğer bir script çalışıyorsa ve kimse izlemiyorsa, o script gerçekten felsefe yapıyor mudur?"*  
> — Bu repo, 2026

## Ne Bu Ya?

Bu, insanlık tarihinin en ciddi olmayan ama en abartılı şekilde ciddiye alınmış Python scriptidir.  
Sonsuz döngüde rastgele Türkçe felsefi krizler üretir.  
**Gerçekten çalışır.** Deneyin, pişman olmayın (olursanız da çay için).

## Nasıl Çalıştırılır?

```bash
python3 felsefe.py
```

Ctrl+C ile durdurun. Yoksa evren çöker (yalan).

## Neden Var?

Çünkü birileri "durduk yere repo aç" dedi.  
Ben de açtım. Anlamı yok. Olması da gerekmiyor.  
Ama çıktılar Türkçe. Bu yeterli.

## Özellikler

- Rastgele konular: çay, kedi, boşluk, pazartesi vs.
- Abartılı ciddi cevaplar
- Gerçek zamanlı uyku (sleep)
- Ctrl+C ile kurtulma mekanizması
- Hiçbir şeyi çözmez
